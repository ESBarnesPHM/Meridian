# Meridian EMR

Static simulation EMR for pediatric patient safety education.

## GitHub Pages setup
Upload these files directly to the root of your repository:

- index.html
- style.css
- app.js
- data.js

Then enable GitHub Pages:
Settings → Pages → Deploy from branch → main → /root.
